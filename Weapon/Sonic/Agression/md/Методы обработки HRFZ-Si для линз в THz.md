# Методы обработки HRFZ-Si для линз в THz

HRFZ-Si обрабатывают стандартными методами полупроводниковой оптики для получения линз с точностью λ/100 (при 633 нм).[^1][^2]

## Основные методы

Двухсторонняя полировка до оптического качества (Ra <10 нм) на алмазных пастах или CMP (химико-механическая) для плоских поверхностей; для сфер — CNC-шлифовка из "шаровых" заготовок диаметром 2–12.7 мм.  Диаметр до 100 мм, толщина 1–5 мм.[^3][^2][^1]

## Просветление и AR-покрытия

- Механическая обработка: Дифракционный рельеф (глубина 29 мкм) или микрорельеф для снижения отражения.[^1][^3]
- Глубокое реактивное ионное травление (DRIE): Тонкие протравленные слои (0.5–1 мкм) для AR-эффекта, затем склеивание с HDPE-пленкой (350 мкм) пресс-молдингом при 1414°C.[^4][^1]
- Пресс-молдинг HDPE: Нагрев сборки (клей + покрытие) с давлением для интерференционных AR-слоев, повышая пропускание в 1.45 раза при 0.14 THz.[^4]

Методы обеспечивают широкополосность (0.1–10 THz) и совместимость с мощным излучением.[^5][^4]
