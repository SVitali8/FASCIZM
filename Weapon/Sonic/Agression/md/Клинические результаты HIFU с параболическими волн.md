# Клинические результаты HIFU с параболическими волноводами

Параболические волноводы в HIFU (double-parabolic-reflectors) показывают высокую эффективность в лабораторных тестах, усиливая ультразвук в 20 раз и комбинируя термическую абляцию (>80 МПа, 1–2,5 МГц) с механической вибрацией (1 кГц–2,5 МГц) для ускорения разрушения тканей. Клинические данные по этой конкретной конструкции ограничены экспериментами (in vitro на тканях), но общие HIFU-результаты с фокусировкой подтверждают безопасность и эффективность.[^1][^2][^3]

## Лабораторные результаты

Волноводы генерируют плоский фронт волны для точной абляции, с усилением энергии ~24% и вибрацией на кончике для histotripsy. По сравнению с классическими HIFU, ускоряют терапию за счет контактных механических эффектов, сохраняя частоту до 2,5 МГц (глубина проникновения >10 см).[^2][^3]

## Клинические данные HIFU (аналогичные системы)

- **Рак простаты**: Безрецидивная выживаемость 76–95,5% через 3–5 лет (n=100+), медиана ПСА 0,07–1,8 нг/мл; лучше QOL vs радиотерапия.[^4][^1]
- **Эссенциальный тремор**: 75–89,4% редукция тремора через 1–12 мес (n=4–15); постепенное формирование очага абляции.[^5]
- **Фиброиды матки**: Значительное снижение симптомов (кровотечения, объем узлов); успех в 80–90% случаев.[^6][^7]


## Сравнение исходов

| Показатель | Результаты | Источник |
| :-- | :-- | :-- |
| Выживаемость (простата, 5 лет) | 76–95% без рецидива [^1][^4] | Клинические испытания |
| PSA-надир | <0,1–1,8 нг/мл [^4] | След-up >5 лет |
| Побочные эффекты | Минимальные (нет диссекций); эволюция очага 1–3 мес [^5] | n=50–200 |
| Ускорение терапии | В 2–3 раза vs стандарт HIFU [^2] | Лабораторно |
