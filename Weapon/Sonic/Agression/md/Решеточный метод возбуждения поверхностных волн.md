# Решеточный метод возбуждения поверхностных волн

Решёточный метод возбуждения поверхностных волн (ПЭВ, поверхностных плазмонов-поляритонов) использует периодическую дифракционную решётку на интерфейсе для фазового согласования света с волновым вектором ПЭВ (k_SP > k_0). Это один из двух основных оптических методов (наряду с призменным), эффективный для сенсоров и нанофотоники с коэффициентом связи до 50–70%.[^1][^2][^3]

## Принцип работы

Дифракционная решётка с периодом d рассеивает падающий свет, добавляя волновой вектор решётки: k_x = k_0 sin θ ± 2π m / d (m — порядок), где θ — угол падения.[^1]
Резонанс при k_x = Re(k_SP) ≈ k_0 √(ε_m ε_d / (ε_m + ε_d)), для Ag-SiO2 на λ=1 мкм — d ≈ λ / (√ε - sin θ).[^3][^1]
Ширина резонанса Δk ~ 50–200 см⁻¹, Q-фактор ~10⁷ для резонансных решёток.[^1]

## Геометрия и эффективность

Решётка наносится на поверхностно-активную среду (металл-диэлектрик); нормальное или наклонное падение (θ=45°).[^3][^1]
Оптимизация: топология или ширина штрихов для 50% связи (Gaussian beam); обратное направление (contradirectional).[^4][^3]
Потери: из-за ширины линии ПЭВ и рассеяния; улучшение — резонансные решётки.[^1]

## Сравнение с призменным методом

| Метод | Преимущества | Недостатки |
| :-- | :-- | :-- |
| Решёточный | Простота, прямое наблюдение | Рассеяние, чувствительность к поляризации[^1] |
| Призменный | Высокая эффективность (~90%) | Сложность установки призмы [^1] |

Применение: ПЭВ-датчики, SPP-генерация в плазмонике.[^2][^1]
