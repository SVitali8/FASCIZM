# Для связи

Пьезокерамические излучатели используются для акустической связи, особенно ультразвуковой (US), где передача данных через звук в воздухе, воде или твёрдых средах (до км в воде).[^1]

## Применения в связи

В гидроакустике (сонары): пьезотрубки/полусферы генерируют низкочастотный УЗ (10–100 кГц) для дальнобойной связи с AUV или маяками.[^1]
Воздушная связь: 20–40 кГц для NFC-подобных систем (data rate 1–10 кбит/с, расстояние 1–10 м).[^2]
Через стенки/металл: контактные преобразователи для НК (неразрушающий контроль).[^3]

## Схема работы

1. Модуляция: FSK/PSK на несущей (напр. 40 кГц) от микроконтроллера.
2. Драйвер: Усилитель (20–200 В RMS) с LC-резонансом.
3. Приём: Аналогичный пьезо + детектор (компрессор + демодулятор).[^2]

## Пример: УЗ-связь на Arduino

```cpp
// Передатчик
tone(8, 40000 + bit ? 1000 : 0, 100);  // FSK 39/41 кГц

// Приёмник: ADC + FFT или envelope detector
```

Библиотеки: DataOverSound, ChirpModem.[^2]
