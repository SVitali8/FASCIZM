# Как возбудить моду TE10 в волноводе

```
Мода TE<sub>10</sub> в прямоугольном волноводе возбудится, если источник поля создаст электрическое поле, соответствующее её структуре — синусоидальное по ширине (x) с максимумом в центре широкой стенки.[^6][^10]
```


## Основные методы возбуждения

```
- **Штыревой зонд (электрический вибратор)**: Металлический штырь от коаксиальной линии вводится перпендикулярно широкой стенке в центр (x=a/2), где E<sub>y</sub> максимальна. Отражающий поршень на расстоянии λ/4 обеспечивает направленное распространение и согласование.[^6]
```

```
- **Петля связи (магнитный дибратор)**: Маленькая рамка в плоскости, перпендикулярной H<sub>φ</sub> (магнитным линиям), размещается в пучности H-поля для индукции тока.[^6]
```

```
- **Апертурное (отверстие)**: Узкое прямоугольное или круглое отверстие в торцевой стенке, поляризованное параллельно E<sub>y</sub> основной моды.[^4]
```


## Практические условия

```
Работайте выше f<sub>c(TE10)</sub> = c/(2a), но ниже f<sub>c</sub> следующих мод (TE<sub>20</sub>, TE<sub>11</sub>) для одномодового режима — высшие моды затухнут экспоненциально. Согласование настраивается длиной зонда/поршня и формой перехода.[^3][^6]
```
