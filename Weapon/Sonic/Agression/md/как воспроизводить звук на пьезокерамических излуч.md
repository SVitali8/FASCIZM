# как воспроизводить звук на пьезокерамических излучателях

Пьезокерамические излучатели воспроизводят звук за счёт обратного пьезоэффекта: переменное напряжение вызывает механические колебания, генерируя акустические волны в слышимом диапазоне (200–5000 Гц).[^1][^2][^3]

## Принцип работы

Подайте на излучатель AC-сигнал на резонансной частоте (обычно 1–5 кГц для зуммеров), амплитудой 5–20 В для громкости до 90–100 дБ.[^4][^5][^6]
Простой способ — ШИМ от микроконтроллера (Arduino/ESP) с частотой тона и duty cycle 50%.[^7][^2]
Для мощного звука используйте драйвер с бустом до 30–50 В и резонансный контур (LC).[^6][^8]

## Базовые схемы

### Пассивный зуммер (самогенерация)

- Подключите к генератору прямоугольных импульсов (1–4 кГц).
- Схема: источник 3–12 В → резистор 100–1к Ом → пьезо (параллельно конденсатор 10–100 нФ).[^7]


### Активный (с драйвером)

Две транзистора (NPN+PNP, напр. BC547/BC557) в мультивибраторе:

```
Vcc (5-12В)
 |
[100к пот]
 |  
BC547 -- BC557 -- Пьезо -- GND
 |         |
[0.1мкФ] [R=1к]
```

Настройте на резонанс (2–5 кГц) для max громкости.[^6]

## Пример кода Arduino

```cpp
int piezoPin = 8;
void setup() {}
void loop() {
  tone(piezoPin, 1000, 500);  // 1 кГц, 500 мс
  delay(1000);
}
```

Функция `tone()` генерирует ШИМ; `noTone()` останавливает.[^2][^7]

## Характеристики и советы

- Импеданс: 100–1000 Ом на резонансе.
- Напряжение: >5 В для заметного звука, до 50 В с бустом.
- Резонанс: Измерьте осциллографом max амплитуду; варьируется по экземплярам.[^5][^4]
Избегайте DC — только AC; для музыки — PWM или DAC.[^1]
