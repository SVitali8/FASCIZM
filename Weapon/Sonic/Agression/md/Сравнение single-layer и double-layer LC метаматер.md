# Сравнение single-layer и double-layer LC метаматериалов

Single-layer LC-метаматериалы проще в изготовлении, но double-layer обеспечивают сильное электромагнитное coupling, повышая Q-фактор и чувствительность для ТГц-импедансной спектроскопии. Single-layer (один слой SRR) имеют базовый резонанс с умеренной локализацией поля, в то время как double-layer (face-to-face) формируют оптическую полость, усиливая плазмонное взаимодействие и redshift Δf. Double-layer превосходят по сенсорным характеристикам без строгого выравнивания.[^1][^2][^3]

## Сравнение характеристик

| Параметр | Single-layer LC | Double-layer LC [^2][^1] |
| :-- | :-- | :-- |
| Q-фактор | Средний (~100–200) | Высокий (до 549) |
| Чувствительность (Δf/Δn) | Базовая (13–21 ГГц/0.04 RI) | Усиленная (оптимальное расстояние ~λ/4) |
| Coupling | Нет | Сильное EM (E-поля усиливаются) |
| Изготовление | Простое (1 слой) | Сложнее (2 слоя, расстояние критично) |
| Полоса (ТГц) | 0,1–2 | 0,1–1,4 (тонкая, tunable) |

## Преимущества double-layer

В double-layer с электромагнитно-coupled electric-LC резонаторами (face-to-face) возникает резонансная полость, максимизирующая plasmonic interaction; оптимальное расстояние усиливает поле в зазоре для сенсинга биомолекул. Применение: высокочувствительная THz-импеданс-спектроскопия тканей/веществ с минимальными потерями.[^3][^4]

Для embedded-систем (RISC-V/ESP32) double-layer интегрируют в портативные сенсоры с контролем расстояния через пьезоэлементы.[^2]
