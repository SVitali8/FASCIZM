# Методы генерации ТГц излучения с помощью метаматериалов

Методы генерации ТГц-излучения с помощью метаматериалов основаны на резонансных нелинейных эффектах, таких как оптическое выпрямление в структурах с искусственной оптической магнитностью. Эти подходы позволяют получать широкополосные импульсы (0,1–4 ТГц) от тонких слоёв (десятки нм), превосходя эффективность толстых кристаллов ZnTe. Ключ — возбуждение магнитного диполя в сплит-ринг резонаторах (SRR).[^1][^2]

## Основные принципы

Метаматериалы усиливают локальные электрические поля в зазорах SRR и используют циркулирующие токи для резонансной нелинейности второго порядка. При накачке фемтосекундными импульсами (1,5 мкм, 140 фс) генерируется ТГц-излучение за счёт оптического выпрямления, без фазового согласования.[^1]

Эффективность достигает ~1/5 от оптимальных ZnTe-кристаллов (толщиной 0,2 мм), с гигантской поверхностной нелинейной восприимчивостью ~10^{-2} м/В. Эмиссия падает вне резонанса.[^2][^1]

## Типы структур

- **Split-Ring Resonators (SRR)**: Тонкий слой (40 нм) SRR на подложке; магнитный резонанс на 1,5 мкм даёт 0,1–4 ТГц.[^1]
- **Метаповерхности**: Управляемые поляризацией и спектром для поляризованного ТГц-излучения.[^3]
- **3D-метаматериалы**: Для сенсинга и детекции, с LC-резонансами, сдвигаемыми диэлектриками.[^4]

| Структура | Полоса (ТГц) | Толщина | Накачка [^1] |
| :-- | :-- | :-- | :-- |
| SRR-слой | 0,1–4 | 40 нм | 1,5 мкм, 140 фс |
| Метаповерхность | Широкая, поляризованная | <1 мкм | ФС-лазер |
| 3D-мета | 0,1–5 | Микромасштаб | THz-спектроскопия |

## Преимущества и применение

Метаматериалы компактны, интегрируемы и масштабируемы для фотоники, превосходя традиционные кристаллы по эффективности на единицу толщины. Применения: спектроскопия, биосенсинг без контакта, нелинейная оптика. Для embedded-интеграции (как в ваших проектах с ESP32) — возможны гибридные чипы с контролем накачки.[^3][^4]
