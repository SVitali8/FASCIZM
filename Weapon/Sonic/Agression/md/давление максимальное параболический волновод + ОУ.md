# давление максимальное параболический волновод + ОУ + пьезокерамический излучатель стреляющий в волновод

Сформулировать «максимальное давление» в абсолютных паскалях для конкретной связки (парабола + ОУ + пьезо) без точных размеров/мощности нельзя, но можно оценить диапазон и показать, куда ты примерно упрёшься по физике и железу. Ниже — в максимально сухом виде.

## Базовые ориентиры по давлению

Связь SPL и давления:
$L_{p} = 20 \log_{10}(p/p_{0})$, где $p_{0} = 20$ мкПа.[^1][^2]

Типичные точки:[^2]

- 120 дБ ≈ 20 Па (порог боли, уже опасно для слуха).
- 140 дБ ≈ 200 Па.
- 160 дБ ≈ 2000 Па (20 кПа), очень жёсткий режим, референсный для LRAD‑класса устройств.[^2]


## Что даёт параболический волновод

- Хорошо выполненный параболический отражатель даёт выигрыш по уровню в районе 10–20 дБ относительно «голого» драйвера (по измерениям и расчётам для акустических параболиков).[^3][^4][^5]
- При этом падение с расстоянием можно приблизить к «половине» обычного 6 дБ/удвоение (в хороших схемах — около 3–4 дБ/удвоение).[^5]

Упрощённая оценка:

- Если пьезо‑излучатель/рупор сам по себе даёт, скажем, 120–130 дБ @1 м, то параболический волновод (правильной формы, фокус ~1–1,5 м) может подтянуть это до ~130–140 дБ @1 м по оси.[^4][^5]
- Выше имеет смысл говорить только при действительно большой подводимой мощности и/или кластеризации излучателей.


## Пьезо‑излучатель + ОУ + парабола: реалистичный диапазон

Исходя из типичных данных по пьезо‑рупорным твиттерам:[^6][^7]

- Чувствительность 90–95 дБ @1 W/1 m.[^7][^6]
- При +20 дБ по мощности (до 100 Вт пиково на эквиваленте) — +10 дБ (логарифмика), т.е. ~100–105 дБ @1 м.
- Парабола даёт ещё +10–20 дБ усиления по оси при удачной геометрии.[^3][^5]

Итого для «хорошо сделанной» системы:

- Реалистично: 120–135 дБ @1 м в оси параболы при частотах 2–5 кГц.
- Это соответствует примерно 20–110 Па акустического давления.[^2]
- Сверх этого (140+ дБ, сотни Па) уже нужна либо очень большая механика + мощный драйвер (LRAD‑класс), либо ряд излучателей/большое количество модулей, питаемых киловаттами.


## Что ограничивает максимум

1. Размер параболы
    - Минимальный управляемый по диаграмме направленности $f_{\min}$ связан с диаметром тарелки D примерно как $D \approx 2 \lambda$.[^8]
    - Для 2 кГц ($\lambda \approx 17$ см) диаметр тарелки порядка 34 см; меньше — резко падает выигрыш/направленность.[^8]
2. Электрическая мощность и ограничения ОУ/драйвера
    - Обычный ОУ не вытянет нужные токи; нужен либо мощный power op‑amp, либо мост на MOSFET/класс D, способный отдать десятки–сотни ватт на эквивалентную нагрузку пьезо (через трансформатор).[^9][^10][^11]
3. Прочность пьезо
    - Пьезо‑излучатели имеют ограничение по механическому смещению и напряжению; превышение в зоне резонанса приводит к деградации/разрушению.

## Итоговая «сухая» оценка

Если взять:

- Параболический отражатель диаметром 0,4–0,6 м.
- Пьезо‑рупор/твиттер с чувствительностью ~93 дБ @1 W/1 m.[^6][^7]
- Мощный драйвер (десятки ватт эффективных на резонансной частоте).

То примерно можно выйти на:

- SPL по оси ~125–135 дБ @1 м (в импульсном режиме, на частотах 2–5 кГц).
- Это 35–110 Па акустического давления, что уже в зоне, где длительное воздействие опасно для слуха и может вызывать повреждения.[^2]

Точные цифры выше без конкретных: диаметра, частоты, типа пьезо, реальной электрической мощности — уже гадание. Если дашь: D тарелки, целевую частоту, реальную электрическую мощность/тип драйвера, можно прикинуть более плотно (через SPL‑калькулятор и поправки на усиление параболы).
