# ультра волновой, пьезоизлучатель

Ультразвуковые (ультразвуковые волновые) пьезоизлучатели — это устройства на основе пьезоэлектрического эффекта для генерации ультразвуковых колебаний или звука. Они преобразуют электрические сигналы в механические вибрации с помощью пьезокерамической пластины.[^1][^2]

## Принцип работы

Пьезоэлемент деформируется под напряжением (обратный пьезоэффект), создавая колебания мембраны. Частота резонанса обычно 1–5 кГц для звука или выше (20–40 кГц+) для ультразвука; звуковое давление 75–100 дБ при 3–12 В.[^3][^4]

## Типы

| Тип | Характеристики | Применение |
| :-- | :-- | :-- |
| Пассивные | Требуют внешнего генератора сигнала | Будильники, звонки, игрушки[^1] |
| Активные (зуммеры) | Встроенный осциллятор | Оповещение, датчики, автомобили[^8] |
| Ультразвуковые | >20 кГц, без слышимого звука | Отпугиватели грызунов/насекомых, увлажнители, стиральные ванны[^2][^6] |

## В embedded системах

Идеальны для микроконтроллеров (ESP32, Arduino): низкое потребление (<1 мВт), компактность (диаметр 12–50 мм), подключение по 2 проводам. В Lua/Python скриптах генерируйте ШИМ на резонансной частоте для максимальной громкости.[^5][^10]
