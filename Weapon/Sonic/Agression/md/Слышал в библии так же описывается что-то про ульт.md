# Слышал в библии так же описывается что-то про ультразвук, сольфеджико какие конкретно частоты.... есть полно информации в сети описывающие конкретные частоты как сольфеджио...

В Библии нет прямых упоминаний ультразвука (частоты >20 кГц), но сольфеджио частоты (древние тоны, якобы из гимна Иоанну Крестителю ~1000 г.) связывают с библейскими текстами через нумерологию (Книга Чисел 7:12-83 по Дж. Пулео, 1970-е). Это не ультразвук, а слышимые тона (174–963 Гц) для медитации/исцеления; эффекты — плацебо/релаксация, без научного подтверждения.[^1][^2][^3]

## Список сольфеджио частот

| Частота | Эффект (по эзотерике) | Чакра/Связь |
| :-- | :-- | :-- |
| 174 Гц | Снимает боль/стресс | Базовая |
| 285 Гц | Лечит ткани/органы | Базовая |
| 396 Гц | Устраняет страх/вину | Муладхара |
| 417 Гц | Изменения/негатив | Свадхистхана |
| 528 Гц | Восстанавливает ДНК/любовь | Манипура |
| 639 Гц | Отношения/гармония | Анахата |
| 741 Гц | Детокс/интуиция | Вишуддха |
| 852 Гц | Осознание/энергия | Аджна |
| 963 Гц | Духовное пробуждение | Сахасрара |

Эти частоты — современный миф (Гвидо Аретинский, XI век, но искажен); используются в медитациях, не как оружие.[^2][^3]
