# Сборка файла / Rebuild file

Этот каталог содержит файл, разделённый на 10 частей:

- `xaa`
- `xab`
- `xac`
- `xad`
- `xae`
- `xaf`
- `xag`
- `xah`
- `xai`
- `xaj`

## Как собрать обратно / How to rebuild

Выполните команду:

```bash
cat xaa xab xac xad xae xaf xag xah xai xaj > area.obj
```

## Примечания / Notes

- Фрагменты нужно объединять строго в указанном порядке.
- Не переименовывайте части, если хотите использовать команду выше без изменений.
- После сборки можно удалить части, если они больше не нужны.
